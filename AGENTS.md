# AGENTS.md

## Project Overview

Inventory tracking system (EnvanterTakip) with three independent sub-projects. NOT an npm workspace — each sub-project has its own `node_modules` and must be managed separately.

### Sub-projects

| Directory | Stack | Dev command | Port |
|---|---|---|---|
| `EnvanterTakip.API/` | ASP.NET Core 10, C#, EF Core, PostgreSQL | `dotnet run` | 5279 |
| `EnvanterTakip.Admin/` | React 19, Vite 8, TypeScript 6, ESLint | `npm run dev` | 5173 |
| `EnvanterTakip.mobile/` | Expo SDK 54, React Native 0.81, expo-router | `npm start` | 8081 |

## API (EnvanterTakip.API)

- **Target framework**: `net10.0` — requires .NET 10 SDK.
- **Database**: PostgreSQL via Npgsql. Connection string is stored in .NET User Secrets (`dotnet user-secrets`), not in `appsettings.json`.
- **Migrations**: EF Core code-first, located in `Migrations/`. Apply with `dotnet ef database update` from the API directory.
- **Legacy timestamp behavior** is explicitly enabled in `Program.cs:5` (`Npgsql.EnableLegacyTimestampBehavior`). New code should be aware of this.
- **CORS** is locked to `localhost:5173` (Admin), `localhost:8081` (Expo web), `exp://localhost:8081` (Expo native). When adding new clients, update the policy in `Program.cs`.
- **Error handling**: `GlobalExceptionMiddleware` wraps all requests. Swallows exception details in production responses.
- **API surface**: `ProductsController` (CRUD + barcode lookup at `GET api/products/barcode/{barcode}`), `SalesController` (create, get, list). Products cannot be deleted if they have associated sales.
- **Build**: `dotnet build` from repo root (uses `EnvanterTakip.sln`) or from the API directory.

## Admin (EnvanterTakip.Admin)

- **Scripts**: `npm run dev` (Vite dev server), `npm run build` (tsc + vite build), `npm run lint` (ESLint).
- **Lint before committing**: `npm run lint` from `EnvanterTakip.Admin/`.
- Currently a bare Vite React template; `src/App.tsx` is the entry point.

## Mobile (EnvanterTakip.mobile)

- **Entry point**: expo-router, routes live in `app/` directory. Tab layout at `app/(tabs)/`.
- **Scripts**: `npm start` (Expo dev server), `npm run android` / `npm run ios` / `npm run web`.
- **New architecture** is enabled (`newArchEnabled: true` in `app.json`).
- **Typed routes** experiment is enabled — Expo generates route types.
- `@/*` path alias maps to the project root.
- `ios/` and `android/` directories are gitignored (generated by `expo prebuild`).

## Conventions

- **Language**: UI text and code comments are in Turkish.
- **No test framework** is configured in API or Admin. Mobile has a `components/__tests__/` directory but no test runner script.
- **No CI/CD** configuration exists.
- **No pre-commit hooks** or task runners.
