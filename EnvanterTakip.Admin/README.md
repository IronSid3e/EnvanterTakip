# EnvanterTakip Admin Paneli

Şua Tarım Envanter Takip Sistemi için yönetim paneli. Şu an geliştirilme aşamasındadır (WIP).

## Stack

- React 19
- Vite 8
- TypeScript 6
- ESLint 10

## Kurulum

```bash
npm install
```

## Geliştirme

```bash
npm run dev      # Vite dev server (http://localhost:5173)
npm run build    # Production build (tsc + vite)
npm run lint     # ESLint
npm run preview  # Production build'i önizle
```
